# 貝克街烘焙AI — 下載版

## 下載(點了就開始下載)

| 你的 Mac | 下載 |
|---|---|
| **Apple 晶片**(M1/M2/M3/M4,約 2020 年後) | [下載 Apple 晶片版](https://pub-86d1f689f3d3487cbbd22955b0d7ffa8.r2.dev/download/BakingAI-latest-arm64.dmg) |
| **Intel**(2020 年前) | [下載 Intel 版](https://pub-86d1f689f3d3487cbbd22955b0d7ffa8.r2.dev/download/BakingAI-latest-x64.dmg) |

**這兩條連結永遠有效,而且永遠是最新版** —— 出新版時不會換網址,直接再點一次就好。

不確定自己是哪一種?左上角蘋果圖示 →「關於這台 Mac」,看「晶片」那行:
寫 **Apple M…** 選 Apple 晶片版,寫 **Intel** 選 Intel 版。

## 安裝

1. 下載 `.dmg`,點兩下打開
2. **把「貝克街烘焙AI」拖進「應用程式」資料夾**(很重要,見下)
3. 從「應用程式」打開

安裝檔已通過 Apple 官方公證,**不會跳「無法驗證開發者」的警告**。

### ⚠ 一定要拖進「應用程式」資料夾

如果直接在安裝視窗裡開,App 會住在「唯讀位置」,**自動更新永遠不會生效**(這是 macOS 的規定,不是程式的問題)。
App 偵測到這種情況會主動問你要不要幫你搬,按「搬到應用程式」就好。

## 之後的更新

裝好之後**不用再手動下載**。App 會自己在背景檢查、下載新版,下次重開就是新版。

## 下載出問題?

**如果點開 dmg 跳出「電腦讀不到你接上的磁碟」**:

> ⚠ **千萬不要按「初始化…」** —— 那是格式化磁碟的意思。請按「忽略」或「退出」。

這幾乎都是**檔案沒下載完**(不是 App 壞掉)。確認方法:在 Finder 對著檔案按右鍵 →「取得資訊」,看大小:

| 檔案 | 正確大小 |
|---|---|
| Apple 晶片版 | 230,053,811 位元組(約 219.4 MB) |
| Intel 版 | 234,829,041 位元組(約 223.9 MB) |

對不上就是沒下載完,重新下載即可。
