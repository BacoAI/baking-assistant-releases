# 貝克街烘焙AI — 下載版

這裡只放 macOS 安裝檔,原始碼不在此。

## 下載(選一個)

| 你的 Mac | 下載哪一個 |
|---|---|
| **Apple 晶片**(M1/M2/M3/M4,約 2020 年後的機型) | 檔名有 `arm64` 的 `.dmg` |
| **Intel**(2020 年前的機型) | 檔名**沒有** `arm64` 的 `.dmg` |

→ **[前往最新版下載](../../releases/latest)**

不確定自己是哪一種?左上角蘋果圖示 →「關於這台 Mac」,看「晶片」那一行:
寫 **Apple M…** 就選 Apple 晶片版,寫 **Intel** 就選 Intel 版。

## 安裝

1. 下載 `.dmg`,點兩下打開
2. 把「貝克街烘焙AI」拖進「應用程式」資料夾
3. 從「應用程式」打開

安裝檔已通過 Apple 官方公證(notarized),**不會跳「無法驗證開發者」的警告**,直接開就好。
